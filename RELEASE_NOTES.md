## Local Vocal β17

- Поиск текста запускается при загрузке песни, параллельно с разделением. Найденный текст применяется автоматически. LRC доступен сразу, затем локальная модель уточняет подсветку слов.
- Названия файлов с обычным и длинным тире, номером трека и пометками Official Video / Vocals разбираются корректно.
- Исполнитель необязателен: поиск учитывает близкое название и длительность, опечатки и короткие лишние фразы. Регистр имени не создаёт ложную неоднозначность. При действительно неоднозначных версиях нужно уточнить исполнителя.
- Короткие слова с нулевой длительностью больше не удаляются. При привязке заданного текста сохраняются все его слова; пропущенные моделью слова получают приблизительное время между соседями.
- Караоке показывает крупную текущую строку, предыдущую и две следующие. Длинные строки разбиваются на короткие фразы; строка не исчезает во время паузы. Текст остаётся видимым при прокрутке элементов записи.
- Старый фоновый анализ не может перезаписать новую редакцию текста. Ошибки поиска не останавливают разделение песни; прерванную привязку можно повторить.

Обновите через «Меню студии → Обновления», затем перезапустите программу. Для старого проекта нажмите «Текст караоке → Найти текст», чтобы повторно применить текст с новым сохранением коротких слов. Для новых загрузок всё запускается автоматически. LRCLIB получает только название, исполнителя и длительность; аудио обрабатывается локально. Точность распознавания и подсветки не гарантирована, особенно при многоголосии и сильных эффектах.
