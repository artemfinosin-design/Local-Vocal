# Local Vocal β29

- Основные действия бокового меню остаются видны на невысоких окнах. Проверено окно 1280×720: «Эффекты песни» и «ZIP для отправки» полностью видны без прокрутки меню. Длинные списки партий прокручиваются внутри своего раздела.
- Исправлен лишний ресинтез: фразы без коррекции нот сохраняют исходный звук. Движок получает относительный сдвиг, без подмены его исходной высоты вторым трекером.
- Периодическое затухание гласной больше не считается доказательством эха. Настоящие непериодические копии по-прежнему распознаются.
- Зависания учитывают ускорение до последних коротких копий; изменённое соседними повторами спектральное окно не мешает поиску совпадений. Пульсация громкости протяжного гласного не считается копиями слов.
- Предложения зависаний старых проектов обновляются при открытии «Эффекты песни». Предыдущая разметка остаётся в analysis-before-effects-v6.json; записи и исключения сохраняются.
- Точка микрофона распознаёт тихое пение и учитывает шум из настройки голоса. Сравнение с полосками учитывает возраст сигнала в буфере микрофона. После остановки записи график не возвращается к началу песни.

Проверены 59 Python тестов, отдельная проверка эффектов, Node проверка шести регистров и тихого пения. На сохранённой записи No Money: медианная ошибка распознанных нот 45 → 23 цента; попадание в пределах 50 центов 55 → 77%. Сравнение охватило 57 секунд уверенных нот и не является оценкой всех песен.

Распознавание эффектов и мелодии остаётся приблизительным. На исходнике No Money уверенная цепочка скопированных слов не найдена; это не доказывает отсутствие таких эффектов. Новая запись с реальным микрофоном и субъективная похожесть всех эффектов не проверялись.

Обновление: «Приложение → Обновления», затем перезапуск. Для эффектов: «3 · Обработка → Эффекты песни → Добавить в песню → Применить эффекты и пересобрать». Для примера: «4 · Результат → ZIP для отправки → согласие → Сохранить ZIP с примером», затем прикрепите архив к сообщению. Автоматической отправки нет. Пользовательские песни, профили и модели не входят в публичный релиз.
