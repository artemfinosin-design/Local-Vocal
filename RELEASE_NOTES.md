## Local Vocal β12

- Коррекция нот переносит периоды записанного голоса вместо спектральной пересинтезации.
- Личный профиль хранит диапазон, уверенность распознавания и последние настройки; оценки влияют на последующие сборки.
- Числовой профиль и журнал можно скачать без аудио; добровольный ZIP включает диагностику выбранной песни.
- Проверка GitHub Releases, загрузка с прогрессом, проверка SHA-256, установка с перезапуском и откатом.
- История песен, восстановление из корзины, выбор новой песни нажатием.

С β9–β11 обновите файлы один раз вручную, сохранив data, .runtime и models. Для применения новой обработки соберите песню заново. Копирование эффектов остаётся приблизительным.
