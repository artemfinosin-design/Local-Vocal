## Local Vocal β14

- Исправлен запуск: версия обработки сверяется с установленными файлами, старый фоновый процесс заменяется при следующем запуске. Интерфейс показывает обе версии и блокирует сборку при несовпадении.
- Уровень короткого допвокала рассчитывается по спетым фразам, а не по шуму во время молчания. Убран принудительный минимум громкости относительно музыки.
- Соседние подтверждённые хвосты реверберации используются для непрерывной оценки пространства. Пропуск эха заполняется только между совпадающими подтверждёнными задержками.
- Стереоширина использует рассеянное поле вместо одной задержанной копии. Опорные точки коррекции высоты следуют основной частоте голоса.
- Текст караоке и настройка голоса доступны прямо над записью; текст открывается на основной странице.
- Разбор сухого пения показывает попадание в мелодию, диапазон, стабильность, уровни и до трёх советов по измеренным данным. Это техническая оценка, не художественный вердикт.

После обновления закройте окно и запустите программу снова. Соберите сохранённые дубли заново: старые WAV не изменяются. Точное восстановление студийных плагинов не гарантируется. Песни, записи и личные профили не публикуются.
