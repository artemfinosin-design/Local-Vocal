# Local Vocal β31

- Исправлено обрезание ускоряющихся повторов звонкого гласного. Последним копиям не нужна пауза до тишины: проверяются уже ускоряющаяся цепочка и резкая новая атака. Обычная плавная пульсация протяжного гласного по-прежнему отклоняется.
- Начало копии определяется по подъёму громкости, вместо фиксированного отступа на 40 мс от пика. Для коротких атак это уменьшает ошибку времени.
- При открытии «Настроить эффекты» старая разметка повторов обновляется, прежняя остаётся в analysis-before-effects-v7.json. Изменённые предложения требуют нового одобрения; записи и остальные эффекты сохраняются.

Проверены 15 тестов эффектов, включая миграцию старой разметки через локальный HTTP API. Контролируемая цепочка из девяти ускоряющихся копий звонкого гласного распознаётся полностью; прежний алгоритм сохранял пять. Плавная пульсация, в том числе ускоряющаяся, не распознаётся как зависание.

Проверены сохранённые исходники Gimme More и No Money. Число копий в спорной цепочке Gimme More не увеличено: акустические признаки недостаточны для уверенного добавления. Это обновление не подтверждает точное восстановление всех эффектов, нот и автотюна; новая запись с физическим микрофоном не проверялась.

Обновление: «Приложение → Обновления», затем перезапуск. Для обновлённых предложений: «Настроить эффекты → Добавить в песню → Применить эффекты и пересобрать». Песни, записи, профили и личные модели не входят в публичный релиз.
