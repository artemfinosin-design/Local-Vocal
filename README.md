# Local Vocal · Своя версия

Локальная караоке-студия для Windows 10/11 x64: разделение песни, запись партий, коррекция нот, оценка эффектов и сборка своей версии.

## Скачать и запустить

[Последняя версия для Windows](https://github.com/artemfinosin-design/Local-Vocal/releases/latest)

Скачайте `karaoke-studio-beta23.zip` (в следующих релизах номер изменится), распакуйте архив целиком и откройте `SvoyaVersiya.exe`. Первый запуск скачивает библиотеки и модели с индикатором прогресса. Песни и голос обрабатываются локально; для установки нужны интернет и 3–4 ГБ свободного места.

После запуска программа сама проверяет опубликованный релиз. Раздел «Обновления» скачивает новую версию и предлагает установить её с перезапуском. Проекты, записи и скачанные модели сохраняются. С β9–β11 на β12 один раз обновите файлы вручную, сохранив `data`, `.runtime`, `models`.

## Голос и личный профиль

Автотюн использует Praat для поиска высоты и ресинтеза с плавными переходами. Пресет «Студийный» учитывает настройку голоса; сомнительные ноты оригинала проверяются независимым алгоритмом. Личный профиль запоминает числовые измерения, настройки и оценки готовых версий. Можно скачать его вместе с журналом без аудио или добровольно сохранить ZIP с песней и сухим голосом. Автоматической отправки записей нет.

Разделение и определение артистов могут ошибаться. Эффекты оцениваются приблизительно; оригинальные плагины не восстанавливаются один в один. При неуверенном распознавании коррекция пропускается; большие сдвиги и шумная запись могут давать артефакты.

## Выпустить новую версию

1. Измените код и увеличьте `BACKEND_VERSION` в `karaoke-studio/runtime.py`.
2. Обновите `RELEASE_NOTES.md`.
3. Создайте и отправьте тег `v0.НомерВерсии.0`, например `v0.13.0` для β13.
4. GitHub Actions собирает EXE и публикует ZIP с `update-manifest.json` в GitHub Releases. Сборка не включает пользовательские записи или установленные большие модели.

Локальная сборка: Python 3.12, `pip install pyinstaller pywebview pythonnet pillow`, затем `python tools/build_release.py`.
